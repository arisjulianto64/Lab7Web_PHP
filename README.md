# Praktikum 7 - Pemrograman Server-Side PHP

## Deskripsi
Program ini dibuat untuk memenuhi tugas Praktikum 7 mata kuliah Pemrograman Server-Side menggunakan PHP.

## Fitur Program
1. Menjalankan PHP.
2. Variabel, operator, dan percabangan.
3. Perulangan dan array.
4. Function.
5. Form GET.
6. Form POST.
7. Pengolahan data sederhana.
8. Eksperimen mandiri.

## Eksperimen Mandiri
- Menghitung rata-rata tiga nilai.
- Mencari nama mahasiswa menggunakan GET.
- Mengubah angka menjadi format Rupiah.
- Validasi NIM (8–12 digit).
- Membandingkan tombol Reset dan pemrosesan ulang server.

## Cara Menjalankan
1. Simpan folder project di dalam `htdocs`.
2. Jalankan Apache melalui XAMPP.
3. Buka browser.
4. Masukkan alamat:

   http://localhost/Lab7Web_PHP/

5. Pilih latihan yang ingin dijalankan.
